01

只读扫描Read-only scan

读取 KRDS sidecar、电子书和本地 fmcache，不修改 Kindle。

Reads KRDS sidecars, ebooks and local fmcache without changing the Kindle.

02

清晰口径Explicit semantics

区分设备记录、正文精确词数和 OCR 估算值。

Separates device records, exact text counts and OCR estimates.

03

离线看板Offline dashboard

生成可直接打开的 HTML，并输出 CSV 和真实 XLSX。

Creates an openable HTML dashboard plus CSV and real XLSX output.

04

漫画边界Honest manga scope

漫画页数与进度独立呈现；无时长时保持未知。

Manga pages and progress are separate; missing duration stays unknown.

05

历史与成就History and achievements

保留历史快照，展示趋势、连续阅读、周期变化和逐星成就记录。

Keeps history snapshots for trends, streaks, period changes and per-star achievement records.

06

检索与分享Search and share

支持搜索、语言和状态筛选、列显隐、打印、XLSX 导出及离线分享图。

Search, language and state filters, column visibility, print, XLSX export and offline share images.

07

漫画页数进度Manga pages and progress

漫画版读取源文件页数、已读页数、阅读进度和 KFX 位置映射。

The manga edition reads source pages, pages read, progress and KFX position mappings.

08

可选 OCROptional OCR

OCR 默认关闭，启用后仍明确标记为估算值，不覆盖 Kindle 原始值或精确词数。

OCR is off by default and remains clearly marked as an estimate when enabled; it never replaces Kindle values or exact counts.

QUICK START

四步开始Start in four steps

  1. 1

    连接并解锁Connect and unlock

    用支持数据传输的 USB 线连接 Kindle，并在资源管理器中确认盘符。

    Connect with a data-capable USB cable and confirm the drive letter in File Explorer.

  2. 2

    下载并校验Download and verify

    选择版本，核对页面上的 SHA-256 与 Release 中的校验文件。

    Pick an edition and compare its SHA-256 with the Release checksum file.

  3. 3

    运行程序Run the executable

    把 exe 放到本地目录后运行。纯文字版不需要额外依赖。

    Run the executable from a local folder. The text-only edition has no extra runtime requirement.

  4. 4

    打开报告Open the report

    在输出目录查看 HTML、CSV 与 XLSX；分享前请先脱敏。

    Open the HTML, CSV and XLSX outputs; sanitize them before sharing.

LOCAL BY DEFAULT

隐私与只读原则Privacy and read-only behavior

无需 Amazon 登录，不读取云端账号，不要求令牌或 Cookie。报告和历史只写入你指定的本机目录。

No Amazon login, cloud-account access, token or cookie is required. Reports and history stay in your chosen local folder.

  • 不写入、删除、移动或修改 Kindle 文件Never writes to, deletes, moves or modifies Kindle files
  • 不自动下载依赖或 OCR 模型Never auto-downloads dependencies or OCR models
  • 不把 OCR 估算值冒充精确统计Never presents OCR estimates as exact statistics
  • 发布页与测试夹具只使用合成数据The project page and fixtures use synthetic data only

KNOWN LIMITS

已知限制Known limitations

主要验证范围为 Kindle Paperwhite 4、固件 5.16.3.1 与 KRDS v1 sidecar。其他型号和固件不作保证。

The primary verified target is Kindle Paperwhite 4, firmware 5.16.3.1 and KRDS v1 sidecars. Other models and firmware are not guaranteed.

漫画 OCR 依赖外部工具与离线模型。源文件页数可能与 Kindle 内部分页不同，估算结果也可能受渲染和语言判断影响。

Manga OCR depends on external tools and offline models. Source-file pagination may differ from Kindle pagination, and estimates can vary with rendering and language detection.

不支持 Amazon 云端统计，不绕过 DRM，也不提供 macOS 或 Linux 安装包。

Amazon cloud statistics, DRM bypass, macOS and Linux packages are outside scope.
